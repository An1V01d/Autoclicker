# Autoclicker
Это программа-автокликер, которая автоматически нажимает левую кнопку мыши каждые полсекунды.  Управление: Alt + P - включить автокликер. Alt + P ещё раз - выключить автокликер. Программа использует три библиотеки: keyboard - для отслеживания клавиш. mouse - для управления мышью.  time - для создания пауз.
